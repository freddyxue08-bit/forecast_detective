# Forecast Detective

Forecast Detective is a daily guessing game. Every day, everyone gets the same mystery city, and the only clues are its weather stats. The player types a city name (with autocomplete) and is told how far away the mystery city is and in which direction. Keep guessing until you find the right city.

## Tech stack (planned)

- Python + FastAPI (backend API)
- PostgreSQL + SQLAlchemy (database)
- Open-Meteo API (weather data)
- pytest (tests)
- Vanilla JavaScript + Chart.js (frontend)
- Docker
- GitHub Actions (CI)
- Render + Neon (hosting)
